Visit Wizard — التطبيق الكامل

أهم Component في النظام — step validation + state + submit

CreateVisitWizard.php

class CreateVisitWizard extends Component {
public bool $open = false;
public int $step = 1;
public ?int $beneficiaryId = null;
public string $visitType = '';
public string $healthStatus = '';
public array $spiritualNeeds = [];
public string $notes = '';

#[On('open-visit-wizard')]
public function open(?int $beneficiaryId = null): void
{
$this->reset();
$this->beneficiaryId = $beneficiaryId;
$this->step = $beneficiaryId ? 2 : 1; // skip step 1
$this->open = true;
}

public function nextStep(): void
{
$this->validateStep();
$this->step++;
}

private function validateStep(): void
{
match($this->step) {
1 => $this->validate(['beneficiaryId'=>'required|exists:beneficiaries,id']),
2 => $this->validate(['visitType'=>'required|in:home,church,phone,hospital']),
3 => $this->validate(['healthStatus'=>'required|in:good,stable,worse']),
};
}

public function submit(): void
{
DB::transaction(function() {
$visit = Visit::create([...]);
// VisitObserver → audit + FCM auto
});
$this->dispatch('visit-created');
} }

نقاط الخطر في الـ Wizard

1. Re-renders أثناء البحث

كل keystroke يعمل network round-trip. الحل: wire:model.live.debounce.200ms + wire:key على كل item لـ morphing

2. Modal State عند wire:navigate

الـ Wizard في الـ layout يُحافَظ عليه. لكن لو الـ user نُقل بـ navigate وهو في step 2، الـ state يبقى. تأكيد: $this->reset() دايماً في open()

3. Validation Error Display

استخدم $this->clearValidation() قبل كل validateStep() — وإلا errors من step سابق تظهر

4. Alpine ↔ Livewire Bridge

FAB هو Alpine component. يُطلق event بـ $dispatch('open-visit-wizard') ← Livewire يسمع بـ #[On('open-visit-wizard')]

نقاط الخطر — Critical Notes

المشاكل الأكثر احتمالاً أثناء التنفيذ

RTL + Tailwind Physical Properties

Tailwind v3 لا يعكس mr-/ml- تلقائياً في RTL. استخدم ms-/me- (logical) أو rtl: variants. راجع كل directional utility في كل component.

Phosphor Icons — CDN → npm

hot.html يستخدم CDN script (2MB+ icon font). في production: npm i @phosphor-icons/vue أو inline SVGs فقط للـ icons المستخدمة.

Offline Sync Conflicts

الخادم يسجل زيارة offline ثم المخدوم يُعاد تعيينه. الـ sync endpoint يتحقق من الصلاحية قبل الإنشاء → 409 Conflict → يُوضَع في failed state في IndexedDB + إشعار للخادم.

wire:navigate + Persistent Modal

منع navigation أثناء الـ Wizard مفتوح: document.addEventListener('livewire:navigate', e => { if(wizardOpen) e.preventDefault() })
