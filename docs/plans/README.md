# Plans — Convention

- Plans live in this folder with status encoded in the filename:
  `[Planned] Title.md` → `[In Progress] Title.md` → `[Done] Title.md`.
- Completed plans move to `Archive/`.
- Before advancing a phase: tick completed checkboxes and append a dated entry
  to the plan's Progress log. The plan reflects reality before moving on.
- One coherent initiative per plan; big programs get phases, not many plans.
- Technical docs (runbooks, setup guides) belong in `docs/` itself, not here.
