# Plans

This folder tracks execution plans for the ministry system.

## Lifecycle

- `[Planned] <Title>.md`: approved plan, not started yet.
- `[In Progress] <Title>.md`: active work. Update the progress log before moving between phases.
- `[Done] <Title>.md`: completed plan. Move completed plans to `Archive/`.

## Rules

- Keep one coherent initiative per plan.
- Use checkboxes for task tracking.
- Every phase must have clear exit criteria.
- Before advancing to the next phase, update the progress log with what changed and what was decided.
